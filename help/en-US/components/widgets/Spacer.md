# DESCRIPTION

This Widget is an empty place. It draws nothing: what is below it is seen. Use it for the space between the children of a Container with the `Row` or `Column` layout (with `Grow` it takes the space that is left), and as the child of a `Select` Widget for a value that shows nothing.

It has no style. Use the `Rectangle` Widget for a place filled with a color and for lines.
